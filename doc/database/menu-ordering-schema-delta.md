## Keys, relationships, indexes and access

| Child column(s) | Current constraint / delete behavior | Baseline |
|---|---|---|
| package_menu_items(package_id, menu_item_id) | Composite PK in this order | Matches canonical key; JPA Set prevents duplicate values |
| menu_items.category_id | fk_menu_items_category → menu_categories.id / RESTRICT | Matches ERD and baseline DDL |
| package_menu_items.package_id | fk_pmi_package → buffet_packages.id / CASCADE | Matches baseline; Package/Soup V3 precedes V4 |
| package_menu_items.menu_item_id | fk_pmi_menu_item → menu_items.id / CASCADE | Matches baseline |
| orders.session_id | fk_orders_dining_session → dining_sessions.id / RESTRICT (V7) | Current DD records PR #16 RESTRICT, superseding older CASCADE DDL |
| order_items.order_id | → orders.id / CASCADE | Matches baseline and entity child ownership |
| order_items.menu_item_id | → menu_items.id / RESTRICT | Matches baseline; protects order history |

V4 supporting indexes: `idx_menu_items_category(category_id)`, `idx_package_menu_items_menu(menu_item_id)`, `idx_orders_session(session_id)`, `idx_orders_status(status)`, `idx_order_items_order(order_id)`. DD explicitly marks orders.status INDEX; other query indexes should be listed in canonical design when accepted. Entity/link PKs create unique indexes; no other UK exists on these tables.

PostgreSQL V5 enables RLS and restricts anon/authenticated table/sequence access. The new isolated PostgreSQL test checks five RLS flags, both client roles' SELECT/INSERT/UPDATE/DELETE privileges and four ID sequences' USAGE privileges. It does not certify permissions on the shared deployment.
