## Behavior and ownership

Manager ยืนยันนำรายการออกจากรายการใช้งานได้ อาหารที่มี Order history หรือ package membership จะเก็บออกโดยรักษา ID/FK/package links และ snapshot; อาหารไม่มี reference และหมวดว่างลบจริงได้.
หมวดมีเมนูที่ไม่ archived แม้ปิดขายก็ให้ 409; หมวดมีแต่ archived children ให้เก็บหมวดออก.
เพิ่มหน้ารายการเก็บออกและ confirmation กู้คืน: คืนหมวดก่อนอาหาร, ไม่คืน children อัตโนมัติ, อาหารคืนครั้งแรกยังปิดขาย; retry ไม่ปิดขายอาหารที่เปิดกลับแล้ว.
DELETE/archive GET/restore บังคับ Manager ที่ controller และ service. Customer list กรอง archive และ stale order ตรวจซ้ำภายใต้ row lock ก่อน persist.

V18 ตามเลขที่จองใน [PR46](https://github.com/PavaritPramual/buffet-restaurant-management-system/pull/46): Methus V16 / Pavarit V17 / Sirapat V18.
เพิ่ม nullable `archived_at` และ indexes แยก H2/PostgreSQL; ไม่มีการแก้ applied migration, FK, RLS หรือ grants.
[Owner schema/API/FK delta](../database/r01-a-menu-archive-proposal.md) · [ERD/lock sequence](../diagrams/r01-a-menu-archive.md).
